# Drugs, Side Effects and Medical Condition - SQL Analysis

## Project Overview
Data analysis on drugs, side effects, and medical conditions using MySQL.

## Tools Used
- MySQL 8.0
- MySQL Workbench
- Git and GitHub

## Analysis Performed
1. Data Cleaning
2. Top 10 Medical Conditions by Drug Count
3. Highest and Lowest Rated Drugs
4. Average Rating per Medical Condition
5. Prescription vs OTC Breakdown
6. Alcohol Interaction Analysis
7. Pregnancy Category Breakdown
8. Most Popular Drug Classes
9. Most Reviewed Drugs

## Dataset
Source: Kaggle - Drugs Side Effects and Medical Condition
