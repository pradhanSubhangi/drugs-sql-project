# Drugs, Side Effects & Medical Condition — SQL Analysis

## Project Overview
Exploratory Data Analysis (EDA) on drugs, side effects, 
and medical conditions using MySQL.

## Tools Used
- MySQL 8.0
- MySQL Workbench 8.0

## Analysis Performed
1. Data Cleaning (handling NULL values)
2. Top 10 Medical Conditions by Drug Count
3. Highest & Lowest Rated Drugs
4. Average Rating per Medical Condition
5. Prescription (Rx) vs Over-the-Counter (OTC) Breakdown
6. Alcohol Interaction Analysis
7. Pregnancy Category Breakdown
8. Most Popular Drug Classes
9. Most Reviewed Drugs

## Dataset
Source: Kaggle — Drugs Side Effects and Medical Condition
Link: https://www.kaggle.com/datasets/jithinanievarghese/drugs-side-effects-and-medical-condition

## Project Structure
- drugs_analysis.sql → All SQL queries used
- data/ → Original dataset
- results/ → Exported CSV results
